## DoD por módulo (todos obrigatórios)
- [ ] Código movido p/ `backend/src/main/java/com/fablab/<modulo>/{controller,service,repository,entity,dto,mapper}` (+`api/` só se consumido)
- [ ] Entities com `@Table(schema="<modulo>")`; repository só do próprio schema
- [ ] Regra de negócio fora do controller (Service/Action); controller só HTTP/FormRequest/Policy (`can:`/Gate)
- [ ] Migrations em `database/migrations/<modulo>/` preservando tabelas/constraints/seeds do contrato
- [ ] Sem Eureka/Gateway/HTTP entre módulos → `Contracts/` in-process ou evento `Event`/`Listener` (nome preservado)
- [ ] Rotas `/api/<modulo>/**` inalteradas (contrato com o front)
- [ ] `php artisan test` verde + cobertura ≥ 80%; testes 401/403 por rota sensível
- [ ] Código mínimo: reuse > create, sem wrapper/arquivo especulativo (ressalva vira remoção BAIXA/MÉDIA)
